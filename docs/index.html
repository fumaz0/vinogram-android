vinogram

Open-source Telegram client for Android. Purple by default — everything else is the real Telegram you already know.

Download APK View source

v0.0.1 · arm64-v8a · Android 6.0+

Features

Real Telegram

Built on top of Telegram for Android 12.7.0. Chats, channels, secret chats, calls and files work through the regular Telegram servers.

Purple by default

The whole accent palette is rebuilt around the vinogram violet — in both the light and the dark theme.

New identity

Launcher icons, splash screen, chat list wordmark and every in-app logo replaced with the vinogram mark.

Open source

The full source is on GitHub. Package names, protocol strings and URLs stay untouched, so nothing breaks.

Install

  1. Download Vinogram-0.0.1-arm64-v8a.apk from the latest release.
  2. Allow installing from unknown sources when Android asks.
  3. The build uses the beta package, so it installs next to the official Telegram.
