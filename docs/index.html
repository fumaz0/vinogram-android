Features

What is inside

Real Telegram

Built on top of Telegram for Android 12.7.0. Chats, channels, secret chats, calls and files work through the regular Telegram servers.

Purple by default

The whole accent palette is rebuilt around the vinogram violet — in both the light and the dark theme.

New identity

Launcher icons, splash screen, chat list wordmark and every in-app logo replaced with the vinogram mark.

Open source

The full source is on GitHub. Package names, protocol strings and URLs stay untouched, so nothing breaks.

Install

Three steps

1 Download the APK
Vinogram-0.0.1-arm64-v8a.apk from the latest release.
2 Allow unknown sources
Android will ask for permission the first time.
3 Install next to Telegram
The build uses the beta package, so the official app stays in place.
